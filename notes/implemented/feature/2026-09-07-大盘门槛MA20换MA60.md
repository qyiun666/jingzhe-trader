# 决策档案: 大盘门槛均线 MA20 → MA60

Status: implemented — 2026-09-07 用户拍板方案一并落地

## Problem

买入漏斗的大盘门槛与卖出规则 5 共用「沪深300 收盘 ≥ MA20」一根均线。两个问题：

1. 门槛太快要反复抖动：沪深300 2014-2026 实测每年开关 28.5 次（约每 8 个交易日折腾一次），年化 4.1% 反而低于一直满仓的 5.5%，最大回撤仍有 36%，空仓期指数累计 +18.9%（错过上涨多于躲过下跌）。
2. 「长期无计划」的体感根源：门槛关闸日候选 0 → 无计划无邮件，2026-08-19 起连续关闸，用户追问是否故障（不是故障，是设计行为，但档位选快了）。

## Decision

窗口 20 → 60 交易日，语义不变（闸门同时管开新仓与关闸清仓，经候选池为空 → 排名淘汰路径）。落地为：

- `store.MarketMAWindow = 60`（repo_screen.go），`IndexQuote.MA20` → `MA60`，SQL 窗口由常量生成。
- `Screener.SyncBackDays()` = 个股因子窗口 20 + 余量 5 = **25 交易日**；指数的均线深度**不**折进逐日全市场回补，由 `Dataloader` 用单码一次区间调用补齐 60 根（`index_daily` 传 start/end 实测一次调用能拉全）。
- `retention.bar_days` 是 `daily_bar` 的**个股**窗口 = 45 自然日；大盘指数豁免于该规则（`RetentionRule.ExceptTSCode`），因为均线窗口比个股因子窗口深三倍，一起裁就把门槛均线裁没了。
  **陷阱：抬代码默认值对已落库的键无效。** `config_kv` 里 init 写入的 45 优先级高于默认值，2026-09-07 那版把默认抬到 100 并未生效，09-08 实测存量库仍按 45 天裁（指数只剩 32 根 ⇒ MA60 不可算 ⇒ 选股整链报错）。生效动作是 `jingzhe config set`；同时新鲜度门禁的 `IndexRows` 升级为"当日一根 + 累计 ≥ `MarketMAWindow` 根"，用 `INDEX_STALE` / `INDEX_WINDOW` 分开报"没出数"与"均线不可算"，不再拖到选股那一步才炸整条链。
- 均线窗口不需要专门的一次性回补动作：每日同步自带 `syncIndexWindow`，凑不满 60 根就当场报错。前提是当天先补齐 `trade_cal`（窗口起点从日历倒数，日历空则算不出起点）。

## Alternatives considered

- **保持 MA20**：被数据否定——12.7 年年化跑输满仓 1.4pp，开关频率是噪音量级。
- **MA40**：全样本最优（年化 7.7%、回撤 23.4%），但属样本内挑参，与 ma_cross 网格过拟合同类错误，弃。
- **非对称（买 MA60 / 卖 MA20）**：上升趋势回调段指数在 MA60 上方而跌破 MA20，实测一年触发 31.8 次卖出-回买抖动，弃。
- **方案二（拆掉关闸清仓，卖出纯看持仓股，删规则 5）**：语义最纯（用户口述的模型），但放弃系统性熔断，2015 型连续跌停场景无全局刹车，且个股层面无法用指数代理回测，无数据支撑。用户未选，保留为未来选项。
- **规则 5（market_bad）删除**：它是影子死代码（闸开⇔指数≥MA60⇒恒不触发；闸关⇒候选 0⇒排名淘汰先触发），方案一保留仅改名，删除属方案二范围。

## Consequences

- 换来：全样本年化 4.1%→7.6%、最大回撤 36.0%→29.5%、开关 28.5→13.7 次/年；分段验证 MA60 在 2014-2017、2021-2023、2024-2026 三段胜 MA20，最近段（2024-2026）优势最大（9.8% vs 4.9%，回撤 11.0% vs 14.4%）。
- 代价一（V 型首段吃不到，量化于 2026-09-08）：沪深300 2017-04→2026-09 共 2293 个交易日，MA60 关闸 1107 天 = 48%，切成 69 段。若关闸期不空仓、继续持有到段末：**68/69 段为负**，平均 -2.8%/段，69 段连乘 -87%，唯一为正的段只有 +0.42%；段内最深单段 -19.8%。反过来看重开闸的代价：从段内最低点到真正开闸那天平均已涨 3.0%（中位 2.0%、最大 10.8%），而开闸当天起 20 日平均只有 +0.6%（中位 +0.1%）。即 MA60 这一档是"躲过的远多于错过的"，与 MA20 的结论相反（那档是错过上涨多于躲过下跌）。口径注意：这是**指数层面**的代理，策略买的是个股、开闸后重建仓的弹性比指数大，踏空成本会被低估；且未计交易成本。
- 代价二：daily_bar 保留 45→100 自然日，库存约翻倍；夜间同步 26→66 个交易日，Tushare 调用约 130→330 次/晚，流水线变慢数分钟。
- 代价三：改完当日指数仍低于 MA60（4575 < 4720），关闸照旧——改的是长期期望，不是明天出计划。
- 个股侧 MA5/MA20（LLM 证据、TrendUp）与大门槛无关，未动。
