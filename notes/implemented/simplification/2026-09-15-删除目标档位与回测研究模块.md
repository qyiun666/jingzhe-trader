# 决策档案: 删除目标档位与回测研究模块 —— 风控收敛为固定基准参数

Status: implemented

## Problem

系统里混着两套东西：一条「看盘 → 选股 → 出买卖判断 → 出指令单」的主线，和一层套在主线上的
「治理层」——按季度目标进度自动升降风控档位、事后统计 LLM 置信度准不准、离线回补多年历史算因子 IC。
治理层不产生任何看盘/选股/买卖判断，却在每次关键操作上叠了一层间接：
风控参数不是常量而是 `goal` 状态机的输出，买入决策的置信度门槛又被 `review` 的统计盯着，
而 `backtest` 的结论以 12.7 年样本内挑参的形式进入了默认因子方向。

用户口径（2026-09-15）：判断权与下单权都在系统里，人只做执行层；季度目标驱动的档位浮动、
事后归因、深历史回测都不是「做出正确买卖判断」所必需，属过度设计。

## Decision

整体删除三块，风控收敛为**一套固定基准参数**：

- 删 `internal/goal`（1141 行）：季度目标三档状态机 + 落后追赶策略（`unrestricted`/`conservative`/`aggressive`）。
- 删 `internal/review`（528 行）：决策归因（LLM 自报置信度 vs 事后收益），它不喂回决策，只出一份统计。
- 删 `internal/backtest`（1286 行）+ `jingzhe research` 子命令：库外深历史回补 + RankIC/ICIR 度量。

连带改动：

- `risk/params.go`：`GearTable` + `Resolve(base, gear, lock, pace)`（含 `PaceAdjust` 三实现、锁利叠加）
  → `DefaultParams(totalAsset)`，一组固定基准（总仓 90% / 单票 40% / 止损 8% / 移动止盈 5% / 止盈 15% / 置信度 0.55）
  + 持仓数自适应 + 物理熔断收口。取值即原 G1 标准档，行为与「未落后未防守」时一致。
- `RiskParams` 去掉 `MaxSectorPct`（原本只被 goal 消费，已无读者）与 `Bias`（择时倾向无消费者）。
- `order_ticket.gear` 列删除（`store.dropLegacyColumns` 幂等迁移，`hasColumn` 用 `pragma_table_info` 判存在）；
  `config_kv` 的 `goal.state` 键作废；`config/keys.go` 删 11 个 `goal.*` 键与 `risk.max_sector_pct`。
- MCP 工具 12 → 10：删 `set_gear` / `confirm_pace`；`get_portfolio` 不再返 `gear`，`get_brief` 不再返 `goal`。
- 执行链去掉 `gear` 传参：`signal.Service.Generate` / `ticket.Service.Create` / `scheduler.buildTickets` / `pipeline`。
- `market` 包删死代码 `QuarterOf` / `QuarterTradeDays` / `PrevTradeDay`（唯一消费者是 goal）。
- 契约文档同步：README / `MCP-AGENT-GUIDE.md` / `docs/API.md` 的工具计数与清单，
  ARCHITECTURE / PRD 的收缩声明块加一段显式说明。

## Alternatives considered

- **保留 goal、只关掉激进追赶（`unrestricted` → `conservative`）**：改动最小，但档位状态机与
  `goal.state` 状态、`gear` 列、`set_gear` 工具这一整套间接仍要维护，而它不产生任何买卖判断。弃。
- **保留 review 作为「观察指标」**：它确实不干预决策（只写 `calibration` 行），但那是「留着一个没人看的仪表」，
  且它存在的前提（LLM 置信度是唯一软门槛）本就随 goal 的删除而弱化。弃。
- **保留 backtest 的 `ic` 子命令、只删 `backfill`**：IC 度量本身有用，但它的历史全部来自 `backfill` 的库外 CSV；
  且默认因子方向已按实测结论定死，日常运行不再需要复算。弃，结论留在 README（原始方向 IC −0.0896）。
- **保留 GearTable 但砍成单档**：等于把 map 退化成一个常量再散落各处，不如直接给 `DefaultParams`。弃。

## Consequences

- 风控行为变更：仓位上限不再随季度目标进度浮动，恒为固定基准。这是有意为之的取舍——
  用「可预测的固定口径」替换「按目标自动松紧」。个股止损/止盈/移动止盈口径未变（原 G1 值）。
- `get_brief` / `get_portfolio` 的返回字段减少（无 `goal` / `gear`），外部 Agent 若读过这两个字段需适配。
- 配置面收窄：`goal.*` 键不再存在，`config set goal.*` 会报「未知配置键」。
- 老库首次以新二进制打开时自动 `ALTER TABLE order_ticket DROP COLUMN gear`（SQLite ≥3.35 支持）。
- 实测：`go build ./... && go vet ./... && go test ./...` 全绿；`itest/docs_contract_test.go` 的工具注册表
  与三处文档计数一致（10 = 5 读 + 5 写）。
- 相关档案：建尺子（review + backtest 的引入）见 `notes/implemented/feature/2026-09-15-建尺子-决策归因与因子IC.md`，
  其功能已随本次删除下线。
